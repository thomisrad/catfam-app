# CatFam

A tiny family app for logging cat care: feedings, litter, weight, medications, vet visits and notes.

This repository holds only the web page. It contains no cat data and no passwords or tokens. Entries are saved to a separate private repository, and each phone needs its own access token (entered once on the phone) to read or write them.

Open `catfam-log.html` through GitHub Pages and add it to your phone's Home Screen.
